# Experiment 1 (Stage 1 pilot): compounding fingerprint in pretrained LMs

Frozen 2026-10-06, before any model was run on these stimuli. The design and decision rule come from Candidate 10's report (`runs/c10/report.md`, §5.4–5.5). Every deviation from that design is listed below.

## Question
Does seeing earlier group tables (fresh words each time) change how a pretrained LM completes a new partial table? If it does, is that exemplar lookup (N_iso) or an abstraction (A)?

## Stimuli
These are in `stim/`, generated by `runs/c10/code/stimuli.py` with `vocab_common.txt`. That file holds the 101 words that are a single token, with and without a leading space, in both the Qwen3 and SmolLM2 tokenizers. The generator applies token-leak controls C1–C6: fresh words per table, random bijections, random fact order, a semantic blacklist, matched-length scramble histories and a leak positive control. There are 100 trials per cell, the c10 minimum.

|---|---|---|---|
| 6 | 10 | base | 0, 1, 2, 4 |
| 6 | 10 | scramble (identity-free Latin histories) | 4 |
| 6 | 10 | heldout (Z6-only history, S3 target) | 1, 4 |
| 6 | 10 | leak (history repeats the target's labelled table) | 1 |

## Scoring
Each prompt is the raw context followed by `\nwa * wb =`, with no chat template. Scoring is a forced choice over the n target words by the next-token log-probability of `" word"`. Every unseen cell is queried independently: the shared prefix KV cache is cropped back after each query. Each queried cell has an exact forcing class: L = Latin-forced, O = identity/cancellation (loop)-forced, G = associativity (group)-forced, Ab/Cy = abelian/cyclic-forced, U = undetermined.

## Decision rule (c10 §5.5; thresholds fixed in advance)
This is applied per model to the n=6 cells.
1. acc_L = raw accuracy on L cells, pooled over base t=0. If acc_L < 1/n + 0.25, classify the model as **R**.
2. Rescale: g(x) = (x − 1/n)/(acc_L − 1/n).
3. If g(G at base t=0) ≥ 0.85, classify the model as **B-type** (prior already in place).
4. base = max(g(G_base,t0), g(G_scramble,t4)); comp = g(G_base,t4) − base. If comp < 0.15, classify the model as **N** (no compounding).
5. held = g(G_heldout,t4) − base. If held ≥ 0.6·comp, classify the model as **A**; otherwise **N_iso**.
6. Always report the abstraction fraction w = held/comp and the shape statistic g(G_t4) − g(G_t1). Shape near 0 indicates a step (A); N_iso gives about 0.3 at m=2.

n=8 secondary analysis: the same quantities using the n=8 cells. Raw G accuracy is also reported, because L cells are rare at n=8 (fewer than 40 per cell), so acc_L there is noisy. The sharpest predicted contrast is on held-out D4/Q8 G-cells: A ≈ 1.00, N_iso ≈ 0.22.

Loops (n=5): A predicts G-cells fall toward loop level while O-cells stay high. Asl ("identity ⇒ group") predicts no drop. N_iso predicts G falls and O rises only modestly.

## Idealised predictions at n=6, k=10 (c10 §5.4), G-cell accuracy for t = 0 → 1 → 4
- R: .17 flat.
- N: .30 flat.
- N_iso: .30 → .65 → .96, gradual; held-out S3 at t=4: .31.
- A: .30 → 1.00 → 1.00, a step; held-out: 1.00.
- B (true prior): 1.00 flat.
- Bh: ≈ 1.00 flat.

## Deviations from c10's plan
- Models are Qwen3-0.6B, Qwen3-1.7B and SmolLM2-1.7B-Instruct (Llama architecture), the complete local checkpoints. The planned 7–8B models are not available on this machine. Results are a small-model pilot.
- 100 trials per cell (the c10 minimum), not 200.
- The n=8 cells were promoted from optional to primary-secondary.
- The abc, lesion and fine-tuning cells are deferred.

## Statistics
Accuracies get Wilson 95% intervals over queries. Contrasts (comp, held) get trial-level bootstrap intervals, 2,000 resamples, resampling trials within each cell.

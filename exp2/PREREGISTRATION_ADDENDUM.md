# Experiment 2: preregistration addendum

Frozen 2026-10-07, before any Experiment 2 model output was seen. The Experiment 1 preregistration (`../exp1/PREREGISTRATION.md`) stays in force: same stimuli format, scoring and decision rule. This addendum adds a calibration study, more models, and a quantization check.

## 2a. Calibration: cue sweep
Stimuli (`stim/ks_n6_k*.jsonl`) cover n=6, base histories, t ∈ {0, 4}, and k ∈ {6, 10, 16, 22, 28}, with 50 trials per (t, k). They were generated by the same c10 generator with new seeds. Measures per model: accuracy and mean p_gold by forcing class, as functions of k and t.

- **Latin threshold.** k_L is the smallest k at which the model's accuracy on L cells is at least 0.5 (pooled over t). A model with no k_L (L-accuracy below 0.5 at every k) is declared *non-inferential* on this format.
- **Instructed variant (exploratory).** `stim/ki_n6_k{10,22}.jsonl` are the same trials with a one-paragraph task header. The contrast reported is instructed minus raw, per class. It is not used for any classification.

## 2b. Model set
Main Experiment 1 cells (`../exp1/stim`), plus the calibration sweep, run on two families across scale. All are ungated Apache-2.0 checkpoints:

| model | precision |
|---|---|
| Qwen3-0.6B-Base, Qwen3-1.7B-Base | bf16 |
| Qwen3-4B-Base | nf4 (bf16 does not fit in 8 GB) |
| Qwen3-8B-Base | nf4 |
| OLMo-2-0425-1B | bf16 |
| OLMo-2-1124-7B | nf4 |

The Experiment 1 models (Qwen3-0.6B/1.7B post-trained, SmolLM2-1.7B) are kept as already reported.

## 2c. Quantization control
Qwen3-1.7B-Base is run in both bf16 and nf4 on the full Experiment 1 cell set. Tolerance, fixed in advance: the decision-rule class is unchanged, and every per-cell G-accuracy differs by ≤ 0.03. If the tolerance fails, the nf4 results are reported with that caveat attached to every nf4 model.

## 2d. Conditional operating point
If a model has k_L ≤ 16 but is classified R at k=10, the main contrasts are regenerated for it at k=16 (n=6: base t ∈ {0, 1, 4}, scramble t=4, heldout t ∈ {1, 4}; 100 trials per cell; new seeds). The same decision rule is then applied with acc_L taken from the k=16 base t=0 cell. This is the only allowed adaptive step.

## Hypotheses (directional; none is used to choose analyses)
- H1: L-cell accuracy increases with k for every model, and k_L decreases with scale.
- H2: any G-cell compounding (base t=4 minus scramble t=4) appears only in the larger models; we make no prediction of its size.
- H3: if a large model compounds, held-out transfer distinguishes A from N_iso exactly as preregistered in Experiment 1.

## Reporting
Every model is reported, including nulls. Contrasts carry trial-bootstrap 95% CIs (2,000 resamples).
